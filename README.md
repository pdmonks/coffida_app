# Coffida - Mobile Application #

This repository contains resources I developed to produce a mobile application during the final year project of my Software Engineering degree at MMU.

The application was implemented during an assignment to develop an Android app for customers to review coffee shops.

Users can create a profile, giving them the ability to:
- search and select coffee shops
- maintain a list of favourite coffee shops.
- create/update/delete coffee shop reviews including images taken with the device camera.
- read and like/unlike reviews of other users.
- search for nearby coffee shops based on the device location.

I have the video presentation I produced to demonstrate the application.
